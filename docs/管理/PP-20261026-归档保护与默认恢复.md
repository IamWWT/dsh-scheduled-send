# 周期任务归档保护与预置恢复

目标：周期任务不随投递会话归档而消失；预置任务可预览并恢复默认，自定义任务不受默认恢复影响。

- 官方 Schedule 仍是唯一调度、投递、计时和任务持久化服务，不修改 harness。
- 插件保存周期任务配置快照和首次登记的预置基线。官方归档停止会删除原会话任务；确认原会话已归档后，通过公开 `sessionController.create` 和 `schedule.create` 转入新任务会话。
- 只有每隔/每日/每周/cron 被保护。一次性任务保留官方归档停止语义；显式删除、截止到期不自动复活。恢复时按原周期规则安排下一次，不补投归档期间错过的执行；官方任务 id 和投递历史随迁移变化，原会话日志保留。
- 读取公开 `workspaceRegistry` 来判定归档及原工作区；未能恢复须保留快照并在任务页明确显示错误，不能静默丢失。
- 预置基线登记后不随编辑覆盖。恢复入口先展示基线，需用户确认；仅更新/补齐预置任务，不删自定义任务、不重复建同一预置项。操作前保存本机配置备份。
- 本机已有四报源于运行脚本，并非插件内置硬编码模板。新版本首次接管以当前配置登记基线；缺失年报从原创建脚本恢复，不猜测私人知识库路径。

验收：归档删除原记录后仍恰好一份周期任务、重启不重复、原工作区与预置标记保留；显式删除/到期不复活；默认恢复纠正编辑且补齐删除项，自定义任务不变，未登录不能调用。隔离真实归档流程和浏览器按钮验证通过后升版 tgz 安装生产。

回滚：停止当前版本，使用安装前备份 tgz 经官方 CLI 重装并重启；保留新增配置快照，不能删除备份。
